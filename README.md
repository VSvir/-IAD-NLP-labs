# Лабораторная работа №2: Компрессия LLM (Этап 2 — Fine-tuning)

Данная работа посвящена дообучению (Fine-tuning) квантованной модели **Qwen3-8B**, полученной на первом этапе, для восстановления метрик качества.

## Сравнение моделей
Для восстановления качества использовался метод **QLoRA** (Fine-tuning LoRA адаптеров поверх квантованных весов HQQ).

| Показатель | Исходная модель (Baseline) | Сжатая модель (Этап 1) | Дообученная модель (Этап 2) |
| :--- | :--- | :--- | :--- |
| **Метод** | - | HQQ 4-bit | **QLoRA (HQQ 4-bit + LoRA)** |
| **Веса** | [Qwen3-8B](https://huggingface.co/Qwen/Qwen3-8B) | [qwen3-8b-hqq-4bit](https://huggingface.co/Neuro-Poplar/qwen3-8b-hqq-4bit) | [Adapter Link](https://huggingface.co/Neuro-Poplar/qwen3-8b-hqq-4bit-lora-adapter) |
| **Размер весов** | 15622.63 MB | 5893.87 MB | **5923.16 MB** |
| **Compression Ratio** | 1.0 | 2.6507 | **2.6375** |
| **Accuracy (MMLU)** | 0.7106 | 0.6913 | **0.7091** |
| **Performance Drop** | 0.0 | 0.0271 (2.71%) | **0.0021 (0.21%)** |

**Финальный Score (Этап 2)** — **2.6320**  
*(Для сравнения Score Этапа 1: 2.5808)*

## Структура репозитория
- `train.py`: Скрипт для дообучения модели с использованием LoRA на подмножестве MMLU Auxiliary Train.
- `inference.py`: Скрипт для загрузки итоговой модели (Base + Adapter) и проведения финальных замеров.
- `eval.py`: Скрипт оценки из первого этапа.
- `requirements.txt`: Список необходимых зависимостей.

## Установка и запуск

### 1. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 2. Дообучение модели (Fine-tuning)

Скрипт проводит быстрое дообучение на 120 шагах (QLoRA):

```
python train.py
```

### 3. Оценка итоговой модели
Скрипт автоматически подгружает базовые квантованные веса и обученный адаптер:

```
python inference.py --base_model Neuro-Poplar/qwen3-8b-hqq-4bit --adapter Neuro-Poplar/qwen3-8b-hqq-4bit-lora-adapter --fraction 0.2
```

### Методология (Этап 2)
Для компенсации потерь точности после 4-битного квантования был применен метод QLoRA.

- Данные: 1600 примеров из cais/mmlu (auxiliary_train).

- Конфигурация LoRA: rank (r)=8, alpha=16, целевые модули: q_proj, v_proj, k_proj, o_proj.

- Оптимизация: Обучение проводилось в течение 120 шагов с использованием Gradient Checkpointing для оптимизации VRAM.

В результате удалось восстановить точность практически до уровня исходной модели (падение составило всего 0.21%), сохранив при этом высокий коэффициент сжатия (x2.64).
